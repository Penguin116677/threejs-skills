Instalasi

Pasang dalam tiga langkah.

Kait adalah web component biasa. Tempel di tema apa pun yang menerima HTML, atau pakai pembungkus React.

  1. Muat script

    Satu file modul. Rak baru dimuat setelah halaman tampil, jadi tidak menahan konten lain.

  2. Taruh rak di halaman

    Tambahkan tag <kait-rak> di tempat rak harus muncul, lalu pilih scene awal.

  3. Sambungkan katalog

    Arahkan ke file JSON berisi SKU, harga, potongan, dan dua foto datar: depan dan belakang.

<script type="module" src="/vendor/kait-rak.js"></script>

<kait-rak
  katalog="/katalog.json"
  scene="butik"
  mata-uang="IDR"
  ayunan="0.8">
  <!-- daftar produk biasa untuk SEO dan pembaca layar -->
  <a href="/p/sawah-tegallalang">Sawah Tegallalang · Rp229.000</a>
</kait-rak>
import { KaitRak } from "kait-rak/react";

export default function Etalase({ produk, tambahKeTas }) {
  return (
    <KaitRak
      katalog={produk}
      scene="malam"
      onPilih={(p) => tambahKeTas(p.sku, p.ukuran)}
    />
  );
}

FAQ

Pertanyaan yang sering masuk.

Belum terjawab? Tulis pertanyaanmu di formulir akses beta di bawah.

Apakah saya perlu model 3D untuk setiap produk?

Tidak. Kait membentuk kaos 3D dari dua foto datar, depan dan belakang. Kamu cukup memilih potongannya: kaos, oversized, lengan panjang, atau tank top.

Seberapa berat untuk HP?

Rak hanya merender saat terlihat di layar dan berhenti saat tab disembunyikan. Resolusi bayangan dan tekstur menyesuaikan ukuran layar.

Bisa dipakai di Shopify atau WooCommerce?

Bisa. Kait berbentuk web component, jadi bisa ditempel di tema apa pun yang menerima HTML. Plugin untuk keduanya sedang diuji peserta beta.

Bagaimana dengan SEO dan aksesibilitas?

Nama, harga, dan tautan produk tetap ditulis sebagai HTML biasa di dalam tag. Mesin pencari dan pembaca layar membacanya seperti daftar produk.

Kapan rilis publik?

Beta tertutup berjalan sampai awal 2027. Peserta beta mendapat paket Toko gratis selama enam bulan.
